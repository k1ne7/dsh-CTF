# v0.7.0 设计说明（2026-10-30，本地候选）

## 研究依据

- SpiritScout 主仓快照 `40cef32cf057a77fe79b778bfa604e12c7fde306`：[证据汇聚源码](https://github.com/FLIAZ/SpiritScout/blob/40cef32cf057a77fe79b778bfa604e12c7fde306/src/spiritscout/blackboard/convergence.py)。其去重与冲突分开处理；证据冲突需要复核，不由后端假装已裁决。本插件已有共享假设机制，继续保留证据和依赖而不另造任务调度器。
- ARTEX 原始 Autumn-27 地址本次返回404，实际研究的是公开派生仓 `trhhubsd/ARTEX` 的 `4379d692905ccd142547c73d7d11c2ff8958cdaa`，不称为闭源原项目最新版：[Worker](https://github.com/trhhubsd/ARTEX/blob/4379d692905ccd142547c73d7d11c2ff8958cdaa/agent/worker.go)、[Planner](https://github.com/trhhubsd/ARTEX/blob/4379d692905ccd142547c73d7d11c2ff8958cdaa/agent/planner.go)。借鉴单个明确任务、已有上下文交接、预算结束保全发现，不照搬数据库、双图或常驻规划模型。

仅借鉴设计，未复制代码、提示词或Skill；所有新实现位于本项目，不增加模型调用或运行时依赖。

## 为什么不直接照搬

DSH 已有原生 Team/任务板、权限、后台任务和会话。另建一个常驻Planner、每步写图或强制分工会增加往返。本候选只在结果失败、重复或疑似停滞时增加有界反馈。证据/假设工具仍按需使用，普通顺畅路径不加流程仪式。

## 本次可证与不可证

能以回归证明：900字符后证据不再静默丢失；截断可见；不同参数同结果触发提醒；空输出与轮询不误计；新证据解除提醒；Agent状态隔离；不把原文/参数注入反馈；配对评估拒绝缺失配置和明显控制条件不一致。

不能以此声称：模型获得新知识、所有漏洞类型均更快、难题成功率必然提升。精确输出比较只是一种观察，不能自动判定重复语义、读取完整性或成功。自动化对照工具不会核验测试者填写的环境标识和checker结果。
